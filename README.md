# cod-skin-unlocker

Tracks which skins and camos I still need to unlock in Call of Duty by reading my local player stats dump and comparing against the completion criteria I scraped from the game files. I was keeping this in a spreadsheet and got sick of it.

## install

pip install -r requirements.txt

## usage

The tool expects JSON stat dumps from the CoD API exporter I run locally. If the directory is empty or missing, it'll tell you and exit clean.
